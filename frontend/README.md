# AI Sales Assistant - React + Vite Frontend

Modern web frontend for the **AI Sales Assistant** platform built with React, Vite, Lucide Icons, and custom CSS glassmorphism aesthetic.

## Features

- **Dashboard**: Executive summary cards (Total Leads, Hot Leads, Conversion %, Pipeline Value), score distribution visualizer, and activity stream.
- **AI Sales Assistant Chat**: Interactive workspace for real-time customer conversations, automated intent detection, and BANT lead scoring triggers.
- **Leads & BANT Scoring Matrix**: Comprehensive CRM lead list with live search, category filtering (Hot, Warm, Cold), and slide-over lead detail drawer.
- **Analytics**: Conversion funnel metrics and intent distribution visual charts.
- **Meeting Scheduler**: Automated demo and consultation calendar manager.

## Setup Instructions

1. **Navigate to the frontend directory**:
   ```bash
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build Production Bundle**:
   ```bash
   npm run build
   ```
